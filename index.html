Data tersimpan otomatis di browser perangkat ini (localStorage). Gunakan Ekspor untuk cadangan / pindah perangkat.

📖 Panduan cepat

  1. Buat proyek di atas, lalu tambahkan adegan: isi prompt klip (deskripsi visual adegan) dan teks narasi per adegan.
  2. Klik “Salin permintaan untuk Muse” pada proyek, lalu tempel teksnya ke chat Muse — Muse akan membuatkan file klip (.mp4) dan narasi (.mp3) per adegan.
  3. Unduh file dari chat, lalu upload ke repo: klip diberi nama 01.mp4, 02.mp4, … ke folder video/input/clips/; narasi 01.mp3 ke video/input/narration/.
  4. GitHub Actions merender otomatis (cek tab Actions di repo). Hasilnya muncul sebagai video/output/final.mp4.
  5. Perbarui status proyek di sini dan tandai platform yang sudah diposting. Selesai!

Catatan jujur: pembuatan klip & narasi dilakukan Muse di chat (ada batas jumlah video per permintaan), render dilakukan GitHub Actions (gratis untuk repo publik dalam batas wajar), dan posting ke sosial media saat ini dibantu Muse lewat akunmu yang terhubung — dengan persetujuanmu di tiap posting.
